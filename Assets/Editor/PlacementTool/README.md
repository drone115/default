# Placement Tool（Unity 6000.3 用エディタ拡張）

メニュー **Tools > Placement Tool** で開く、モード切り替え式の配置ツールです。

## 導入
`Assets/Editor/PlacementTool/PlacementToolWindow.cs` をプロジェクトの `Assets/Editor/` 以下に置くだけ。

## モード
| モード | 操作 |
|---|---|
| ① 配置 | シーンビューを左クリックした位置にプレハブを配置 |
| ② ライン | 1クリック目=始点、2クリック目=終点。間を「間隔」ごとに一直線に配置（Escで始点キャンセル） |
| ③ グリッド | グリッド間隔・原点を設定し、スナップした位置に配置 |
| ④ 連結 | 基準パーツのバウンズの面（カーソルに近い面）に次のパーツをくっつけて配置。置くたびに基準が最新パーツへ |
| ⑤ 上にコピー | 選択オブジェクトを指定の高さ（既定 4m）上に複製 |

## 共通仕様
- 回転・スケールはプレハブ（コピー元）のまま変更しない（変更するのは位置のみ）
- すべての操作は Undo（Ctrl+Z）で 1 操作ずつ戻せる（ラインで並べた複数個も 1 回で戻る）
- プレハブのリンクは保持（`PrefabUtility.InstantiatePrefab` / 複製は Edit > Duplicate と同じ処理）
- メッシュにコライダーが無くても当たり判定される（`HandleUtility.PlaceObject`）。何も無い場所は「地面の高さ」の水平面に配置
- Alt+ドラッグの視点操作、選択中オブジェクトのギズモ操作はそのまま使える
- 通常の選択操作に戻したいときはウィンドウ上部の「シーンでのクリック配置」を OFF
- Prefab モード（プレハブ編集画面）中は、そのプレハブのルート配下に配置
- 設定・パレットは EditorPrefs に保存され、次回起動時も残る

## 補足
- 連結モードのバウンズは MeshRenderer / SkinnedMeshRenderer / SpriteRenderer（無ければ BoxCollider）から計算した軸平行バウンズ
- 横に連結するときは底面の高さを揃え、もう一方の水平軸は中心を揃える
